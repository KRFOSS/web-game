# 생각의 놀이터

서로 다른 방식의 사고를 요구하는 웹 퍼즐 모음입니다. 메인 페이지에서 여러 개의 짧은 퍼즐을 바로 실행할 수 있고, 기존 3차원 착시 퍼즐인 `시점의 길`도 독립 게임으로 포함되어 있습니다.

## 포함된 게임

1. **빛을 접는 방**
   - 거울 두 장만 배치해 광선을 목표 지점까지 보내는 반사 퍼즐
   - 거울 위치와 `/`, `\\` 방향을 함께 설계해야 합니다.

2. **중력 우체국**
   - 말을 직접 한 칸씩 움직이는 대신 중력 방향을 선택하는 퍼즐
   - 상자는 벽이나 장애물을 만날 때까지 계속 미끄러집니다.

3. **거울 쌍둥이**
   - 하나의 방향 입력으로 두 말을 동시에 움직이는 퍼즐
   - 두 번째 말은 좌우 입력이 반대로 적용됩니다.

4. **한 붓 성좌**
   - 모든 선을 정확히 한 번씩만 통과하는 경로 퍼즐
   - 시작점 선택도 풀이의 일부입니다.

5. **대칭 복원실**
   - 제한된 수정 횟수 안에서 가로와 세로 대칭을 동시에 복원하는 패턴 퍼즐

6. **그림자 조립소**
   - 서로 다른 폴리오미노 조각을 회전하고 배치해 목표 그림자를 채우는 조합 퍼즐

7. **규칙 제작기**
   - 입력과 출력 사례를 보고 두 단계 연산 규칙을 역으로 추론하는 규칙 발견 퍼즐

8. **시점의 길**
   - 실제로 연결된 3차원 경사로가 특정 정사영 시점에서 직선처럼 보이는 착시 퍼즐
   - 공은 Cannon ES 강체 물리와 실제 연속 충돌면을 따라 굴러갑니다.
   - 공이 출발한 이후에도 카메라를 계속 회전해 실제 경사 구조를 확인할 수 있습니다.

## 파일 구성

- `index.html`: 퍼즐 아케이드 메인 화면
- `arcade.css`: 메인 화면과 7종 미니게임의 반응형 스타일
- `arcade.js`: 7종 미니게임의 규칙, 상태, 승리 판정 및 입력 처리
- `perspective.html`: 시점의 길 독립 실행 페이지
- `style.css`: 시점의 길 전용 화면 스타일
- `game.js`: Three.js + Cannon ES 기반 3차원 착시 및 강체 물리 로직
- `.github/workflows/pages.yml`: GitHub Pages 자동 배포 워크플로

## 실행

정적 웹 서버의 루트에서 저장소 내용을 제공하면 됩니다. 로컬에서 간단히 확인하려면 다음과 같이 실행할 수 있습니다.

```bash
python3 -m http.server 8080
```

그 뒤 브라우저에서 `http://localhost:8080`으로 접속합니다.

## 배포

`main` 브랜치에 변경사항이 푸시되면 GitHub Actions가 정적 파일을 GitHub Pages에 자동 배포합니다.
