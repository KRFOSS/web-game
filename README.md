# 시점의 길

카메라 시점에 따라 실제로 떨어져 있는 길이 화면상에서 연결되어 보이면 공이 건너갈 수 있는 웹 퍼즐 게임입니다.

## 조작 방법

- 마우스 또는 터치로 화면을 좌우 드래그해 카메라를 회전합니다.
- 길 끝이 화면에서 충분히 가까워지면 연결이 활성화됩니다.
- 공은 연결된 길을 자동으로 건너 목표 지점까지 이동합니다.
- 키보드에서는 좌우 방향키로도 시점을 조절할 수 있습니다.
- `R` 키 또는 화면의 버튼으로 현재 단계를 다시 시작할 수 있습니다.

## 구성

- `index.html`: 게임 화면과 사용자 인터페이스
- `style.css`: 반응형 화면 스타일
- `game.js`: Three.js 기반 3차원 장면, 카메라, 착시 판정 및 게임 진행 로직

## 실행

정적 웹 서버의 루트에 저장소 내용을 배포하면 됩니다. ES 모듈을 사용하므로 로컬 파일을 직접 여는 대신 HTTP 서버를 통해 실행하는 것을 권장합니다.

예시:

```bash
python3 -m http.server 8080
```

그 뒤 브라우저에서 `http://localhost:8080`으로 접속합니다.

## 배포

저장소에는 GitHub Pages용 Actions 워크플로도 포함되어 있습니다. 저장소 설정에서 Pages의 배포 원본을 GitHub Actions로 지정하면 `main` 브랜치 변경 시 정적 게임이 배포됩니다.
